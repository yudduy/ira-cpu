# CPU-VC Correlation Analysis Module Spec

## Overview
Analyze the relationship between Climate Policy Uncertainty (CPU) index and Venture Capital financing in CleanTech/ClimateTech sectors.

## Data Sources
- **CPU Index**: Generated by existing `src/cpu_index/analysis/indexer.py` (monthly, 2008+)
- **VC Data**: `ClimateTech_Deals.csv` (PitchBook export, 46K+ deals, 2000-2025)

## Scope
- **Deal Types**: VC-only (Seed, Early Stage VC, Later Stage VC, Angel) - ~14K deals
- **Time Granularity**: Monthly
- **Metrics**: Deal count, total amount, median deal size, stage distribution, sector breakdown
- **Methods**: Stationarity tests, VAR, Granger causality, cross-correlation, visualizations

## Module Structure

```
src/cpu_index/analysis/
├── vc_loader.py        # Load and preprocess VC deal data
├── vc_aggregator.py    # Aggregate VC metrics by month
├── correlation.py      # Time series correlation analysis
└── vc_visualizations.py # CPU-VC trend visualizations
```

## Implementation Details

### 1. vc_loader.py
- Load ClimateTech_Deals.csv (skip 6 header rows)
- Filter to VC deal types: ['Seed Round', 'Early Stage VC', 'Later Stage VC', 'Angel (individual)']
- Filter to completed deals only
- Parse dates, clean deal sizes
- Filter to 2008+ (to match CPU index availability)

### 2. vc_aggregator.py
- Aggregate by month:
  - `deal_count`: Number of deals
  - `total_amount`: Sum of deal sizes (in $M)
  - `median_amount`: Median deal size
  - `stage_counts`: Dict of counts by VC round
  - `sector_counts`: Dict of counts by industry sector
- Handle missing deal sizes (use available data, track coverage)

### 3. correlation.py
- **Stationarity Testing**:
  - ADF test (null: unit root)
  - KPSS test (null: stationary)
  - Difference series if needed
- **Cross-Correlation**: Correlation at lags -12 to +12 months
- **Granger Causality**: Test if CPU Granger-causes VC metrics (and vice versa)
- **VAR Model**: Vector autoregression for impulse response analysis
- Return structured results with p-values, coefficients, interpretations

### 4. vc_visualizations.py
- Dual-axis time series: CPU index vs VC deal count/amount
- Cross-correlation plot with confidence bands
- Rolling correlation (12-month window)
- Stage distribution over time
- Export to PNG/SVG

## Dependencies
- pandas, numpy (data manipulation)
- statsmodels (ADF, KPSS, Granger, VAR)
- matplotlib, seaborn (visualizations)

## Output
- Monthly aggregated VC metrics CSV
- Correlation analysis results JSON
- Visualization PNG files
- Summary report markdown
